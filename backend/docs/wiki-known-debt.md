### 已处理（历史债，防重提）

- 双链点击跳转（编辑/预览两模式）：已实现，含悬空链「点击询问创建」。
- `[[` 补全 ↑/↓ 跳回第一项：已修（keyup 重建弹层保留 index）。
- 切页不保存 / 重复请求 / 关标签不释放锁 / 删文件夹残留坏标签 / 移动目录标签路径失效：已修。
- 软删库 30 天 GC：已在自动提交循环实现（`auto_commit._gc_deleted_vaults`）。
- pull 冲突返回 409 + 冲突文件列表、push 拒绝 409：后端契约 + 前端弹窗均已实现。
- `conflict()` 不支持 extra 字段导致 pull 冲突 500：已修。
- VaultManager 详情 N+1：已修——新增 `GET /wiki/vaults/overview` 批量接口（文档数走一次 Mongo 聚合、git status 并发），前端列表页从 N+1 次请求降为 2 次。
- GraphView echarts 全量 chunk：已修——改 `echarts/core` 按需注册（graph 系列 + tooltip + canvas 渲染器），chunk 1,040KB → 440KB（gzip 345KB → 149KB）。
- `[[` 补全在代码块/行内代码内触发：已修——`detectLinkTrigger` 沿祖先链检查 `CODE/PRE` 跳过。注意 `data-block="0"` 是 Vditor IR 所有块级元素的通用标记，不能用来识别代码块（第一版踩过这个坑）。
- 标签搜索 `#` 解析脆弱：已修——前端 `#/＃` 前缀识别为标签搜索；后端剥离前缀 + 全角转半角 + 大小写不敏感精确匹配。
- 删文件夹时未保存改动静默丢弃：已缓解——删除确认弹窗会预先列出受影响标签中未保存修改的数量并明示「删除后将无法恢复」。
- 同账号多窗口编辑同页不互斥：已修——锁升级为窗口级令牌（`用户名@windowId`，windowId 存 sessionStorage 按标签页隔离，重载保持）；前端只释放自己持有的锁，只读窗口不会误抢；持锁期间无令牌保存被拒；旧客户端不带 holder 时退化为原用户名语义。
- 图谱大库性能：已有截断（`GRAPH_NODE_LIMIT = 500` 按度数取 top）。
- 直接 URL 进入 cloning 状态库：只返回空树，不 500。

回归轮（2026-10-18）新修，均已前后端测试 + 浏览器实测：

- 窗口级锁上线后所有保存 409：保存链路未传 holder。已修——`PageSave` 加 `holder` 字段，save 端点透传，前端 `savePage`/`doSave` 带 `lockState.currentHolder()`；保存后兜底续锁段同步写 `lock_token`。
- 同账号另一窗口持锁时前端无任何提示：openPage/switchToTab 先看 `res.locked_by === 用户名` 就跳过 acquire，窗口级锁下该判断失效（可能是别的窗口持有）。已修——有编辑权限统一走 acquire，由后端按窗口令牌裁决（409 → 只读 + 轮询等待）。
- 重命名/移动单文档后树出现幽灵节点：move_page 改了 `page.path` 不落库，upsert 索引又按新路径另建记录。已修——先 `save()` 改路径（含 folder）再重建索引。
- 移动文件夹时其下已打开标签前缀不同步：树节点 path 是不带 .gitkeep 的目录路径，旧代码只认 `/.gitkeep` 结尾。已修——非 .md 源路径即视为目录移动。
- 重命名/移动后 URL 不同步：程序化改 activeTabPath 不会触发 el-tabs 的 tab-change（EP 2.9 只在用户点击时发该事件，源码 `setCurrentName` 的 trigger 参数），旧代码依赖一个不存在的"重复事件"抑制标志，反而把 closeTab/forceCloseTab 里对 onTabChange 的直接调用吞掉。已修——删除整个 suppress 标志机制，抽出 switchToTab 供程序化切换直接调用；重命名/移动后手动 router.replace。
- 提交弹窗未提交数过期：openCommit 不刷新状态，计数停留在上次加载。已修——打开弹窗前 refreshStatus。
- 无链接文档的图谱邻域视图整页空白：图谱接口不返回孤立节点，邻域过滤结果为空。已修——邻域子集自动补中心节点，提示条加「该文档暂无入链 / 出链，仅显示自身」。
